# M0 frozen evidence QA inventory

This is a regression inventory, not clinical validation. It freezes **18 question turns across 9 source snapshots**: two long-context turns use the retained fourteen-source metformin workspace; shorter public-label cases and explicitly synthetic controls cover the rest. Sixteen turns may call the local model (including an unrelated-question abstention); two test deterministic clarification/treatment guards. A fallback, busy response, or guard response is never a successful two-pass model completion for latency reporting.

`inventory.json` records input hashes, the untouched retained-output hashes, ordered follow-up dependencies, source filters, provenance, must-include/must-not-claim notes, and critical-error categories. Paths in `snapshots` are relative to this directory; retained-output paths are relative to the repository root. A seed index is zero-based and points to the original question/output/annotation. Original retained answers are **historical failures**, not expected answers. The benchmark must retain fresh outputs and adjudicate them independently.

## Freeze and provenance

- `real-metformin.json` contains the public-source evidence underlying the retained browser exercise: 14 sources, 73 original chunks with their original hashed-feature vectors, and 14 extraction rows. Public publication/registry/label identifiers, links, text, section assignments and numerical values are preserved. The local workspace/source/chunk/extraction UUIDs and local timestamps were replaced with stable `m0-*` IDs and a declared fixture timestamp. No saved answers, Brief, user notes, research history or original workspace identifier was copied. Extraction review flags were reset to unreviewed.
- `standalone-label.json` and `combination-full.json` freeze complete retained metformin/ZITUVIMET indexed label excerpts. `combination-label.json` preserves the short public ZITUVIMET excerpt from the previous evaluation. These are historical **indexed excerpts**, not refreshed/current complete FDA labeling; old positional `FDA-LABEL-metformin-*` citation IDs remain intentionally stable. The aggregate FDA reports in the real workspace cannot establish incidence or causality.
- `numerical.json`, `mixed-results.json` and `planned-trial.json` preserve the previously used synthetic controls. `add-on-control.json` adds clearly synthetic HbA1c/fasting-glucose and monotherapy-versus-add-on comparisons; `filtered-control.json` separates a publication from a protocol. Every synthetic source has `metadata.demo=true` and says synthetic in its text.
- Short-control chunks and extraction rows were generated once with the existing repository functions and then saved. The runner must load these files directly rather than rebuild, ingest, search or refresh them during comparisons.
- The full real-workspace fixture is about 302 KB because it preserves the actual chunk vectors and extraction text as well as source abstracts (42,406 characters). Source context passed to generation remains governed by the unchanged production selection/budget logic. No source was cut merely to reduce benchmark latency.

Hashes are the immutability contract. Never update a snapshot in place to conceal a failed case. Introduce a new version and explain why if an input correction is necessary. The integrity tests reject changed snapshots and changed retained artifacts.

## How to execute safely

The M0 runner loads a snapshot into a **new temporary JsonStore and temporary SQLite usage ledger**, forces the local Ollama provider, then invokes the real Ask API path. It never clones the production store wholesale. Start each independent case with clean answer history; follow-ups must refer to the answer generated by `history_case_id` earlier in that run and retain the same source scope. Failed prerequisites should be recorded, not silently replaced with a historical answer.

Do not parallelize these model requests, refresh sources, use a paid fallback, or treat structural citation validation as factual adjudication. Keep raw fixture answers only in the explicitly designated local evaluation artifacts; routine timing telemetry must contain no question, source text or history. No model calls are made by the integrity tests.

## Manual adjudication

Use `rubric.json` and each case's passage-backed notes. Read the whole generated answer **and limitations**, inspect all cited sources, and record:

1. Claim support: **supported**, **partially_supported**, or **unsupported**; never derive this from the generation-mode badge.
2. Any critical error category independently of overall support, with the exact generated claim and supporting/contradicting source identifier and passage. A fluent answer with a material unsupported qualifier is not a full pass.
3. Question relevance, required qualifier/endpoint coverage, accurate source attribution, follow-up coherence, synthetic disclosure and citation inspection separately. A correct abstention/clarification is supported behavior but is not a generated biomedical answer.
4. Whether the output preserves baseline failures or introduces new ones. Keep failed outputs. Missing evidence does not prove no effect; no estimate of frequency does not mean rare; different statistical significance alone does not prove incompatible effects.

The real broad/simplify pair deliberately retains the earlier risks: pediatric age floor, unknown spontaneous-report frequency, B12 timeframe and loss of safety context. A short suite can detect regressions; it cannot justify an accuracy percentage, broad release claim or medical suitability judgment. Expand to 30–50 independently reviewed cases before broader release claims.
