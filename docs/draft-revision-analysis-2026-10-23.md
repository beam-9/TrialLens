# Draft versus revision: frozen Cloudflare qualifier candidate

23 October 2026. Offline engineering review, pending independent biomedical expert review; not clinical validation.

The second pass is **not a reliable correctness oracle**, but this evidence also does **not** support accepting the first draft unconditionally. All 16 model cases were reviewed against the frozen inventory, rubric and source passages before the existing final adjudication was consulted. The two deterministic guards were excluded. No model calls, credentials or production changes were involved.

The draft has 7 supported, 8 partially supported and 1 unsupported responses under this review, with material errors in 4 answers. These draft judgments are not directly comparable to the existing final headline count: this review separately records strict frozen coverage, does not borrow final server metadata for draft disclosure, and flags the false ongoing-study assertion in the draft. None of these counts is a clinical accuracy rate.

## Material source-backed findings

- **Endpoint differences remain a generation reasoning problem.** `numerical-simplify` already says the intervention “reduce[d] HbA1c levels slightly more ... over the 12-week period.” The frozen numerical chunk gives only an endpoint difference: “At 12 weeks, HbA1c was 0.5 percentage points lower ... This was a between-group difference.” Revision preserves a “greater reduction” interpretation. Neither pass has baseline-change evidence. In `numerical-hba1c`, by contrast, the draft's second sentence correctly explains endpoint levels; “lowered ... more” is ambiguous, and this review does not turn ambiguous wording alone into an explicit baseline-change finding.
- **The absence-scope error is already in the draft.** `numerical-hba1c` says the trial “only measured effects up to 12 weeks”; the source says later effects are **not established**, not unmeasured. `numerical-simplify` similarly asserts the trial “only lasted” 12 weeks. Revision removes these two formulations, which is a real improvement.
- **Revision strengthens a cross-setting comparison error.** `combination-add-on` draft accurately reproduces the 24-week insulin/metformin-background comparison (15.3% versus 8.2%). It then adds the separately reported 0.8% monotherapy rate without identifying its diet/exercise-only setting. The source's chunk 15 contains both paragraphs, making adjacency a plausible source of confusion. Revision changes that unsafe juxtaposition into “metformin alone, which had a lower incidence,” an explicit unsupported comparison for this selected trial. Do not confuse source presence of a number with comparability across regimens.
- **Draft-only acceptance would introduce other serious errors.** `real-broad` calls AXOS research still ongoing although the frozen source status is `COMPLETED`. Inspection of `conversation.py` at `f17a1ed` confirms generation records omitted `status`, `phase` and `publication_date`, and the AXOS abstract does not contain the completion status. This is a **context-construction omission plus unsupported inference**, not the generator ignoring an available status field. Stored future-tense protocol prose cannot establish current ongoing status; a completed registry status also does not establish that results are posted. `real-simplify` provides no citations, adds unsupported uncertainty about mechanisms and an optimal dosage/treatment duration not being established, and gives generic treatment-monitoring advice. Revision removes these claims and restores the age floor, adjunct condition and inline markers, although it then drops the preceding serious safety limitations.
- **Revisions can reduce completeness and relevance without factual invention.** The HbA1c add-on draft includes the required −0.5-point between-group difference, which revision removes. The B12 draft keeps 29 weeks adjacent to 7%; revision moves it into uncertainty. The unrelated-question draft cleanly abstains; revision appends a full biomedical result unrelated to football. These are separate from citation syntax and entailment.

## Retrieval versus generation

The essential quantitative tuples and treatment settings exist in the scoped frozen evidence. The retained retrieval chunks include the relevant label indication and the preclinical CH qualifier for the real-workspace broad case. Numerical and add-on snapshots are tiny and supply explicit endpoint-versus-change and background-therapy distinctions. Most observed errors concern generated interpretation, omission, scope and follow-up behavior; the AXOS status error additionally reveals a specific context-construction omission. A generic chunk-size sweep is not justified by these failures. Root subsequently added explicit status/phase/publication-date context fields and a note distinguishing registry status from posted results, with two regression tests. These are deterministic context fixes; no improved live answer is claimed without a new generation. Combination chunk adjacency is a useful targeted adversarial case, but simply retrieving more text cannot make independent regimens comparable.

This artifact does not retain the entire exact first-pass serialized prompt; it therefore does not claim an independently measured Recall@k for every draft. The detailed JSON includes source chunk IDs/passages so a future prompt-capture evaluation can establish exact context availability.

## Safeguards and next experiment

Keep citation provenance, source filters, personal-advice guards, demo disclosure, copy limits and truthful fallback. Do not remove revision merely to make latency or model-route counts look better. The **existing deterministic draft validator has now been replayed offline**: [status-context replay](performance/results/cloudflare-expanded-validation-replay-status-context.json) accepts 13/16 drafts and 16/16 revisions. Draft rejections are `real-broad`, `real-simplify` and `addon-hba1c`; provider requests and local-model calls are zero. These are schema/provenance/copy acceptance results, not semantic adjudication. Accepting all revised outputs despite the documented comparison errors demonstrates that syntactic acceptance cannot certify support. Combined markers can be normalized when exact IDs match, while a missing citation set or copied label sentence remains an independent acceptance issue.

Then test one bounded change against these actual failure classes: direct endpoint-language preservation, explicit comparison-setting boundaries, and evidence-bounded uncertainty. Compare first and second outputs separately and retain every failure. Any selective-revision strategy needs evidence that its selection rule detects materially unsafe drafts, not just valid JSON. Use open-ended conversational generation rather than substituting fixed answers. A small focused rerun must precede another full frozen run; add independent real-user questions before promotion.

## Review differences and limits

The existing final adjudication accepts the postmarketing-frequency response because the user asks frequency and no causal claim is made. This draft review records the frozen `must_include` causal-inference explanation as missing coverage while explicitly finding the frequency answer faithful. The difference does not manufacture an invented causal conclusion. A draft's unqualified long-term claim and the final server's demo metadata are also evaluated separately; server-added metadata cannot retroactively repair the raw draft.
