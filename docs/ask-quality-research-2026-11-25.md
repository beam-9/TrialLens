# TrialLens Ask evidence and coverage experiment — 25 November 2026

## What the evidence establishes

- ALCE evaluates answer correctness and citation quality separately. Citation recall asks whether the cited passage set supports each sentence. Citation precision checks whether individual cited passages contribute support. TrialLens should grade an explicit correction against the correction itself and inspect each linked passage for its contribution. [Gao et al., ALCE, §4](https://aclanthology.org/2023.emnlp-main.398/)
- FActScore measures factual precision by breaking a response into atomic facts and checking each against a source. A short response can score well on emitted claims while omitting requested details, so TrialLens also needs a denominator of answer obligations fixed before seeing the candidate. AIS supplies the complementary human judgment protocol of reading a claim against an independent, identified source. [Min et al., FActScore](https://aclanthology.org/2023.emnlp-main.741/) · [Rashkin et al., AIS](https://aclanthology.org/2023.cl-4.2/)
- The ACL blueprint study found that question-based content plans improved attribution on its long-form QA experiments. RARR improved attribution through separate evidence search and post-editing. Those studies motivate separating stages. TrialLens must measure the transfer of that idea to its frozen evidence, clinical qualifiers and current two-call allowance. [Fierro et al., question blueprints](https://aclanthology.org/2024.acl-long.615/) · [Gao et al., RARR](https://aclanthology.org/2023.acl-long.910/)

## What has already failed here

The latest captured results include dropped uncertainty despite the interval being present, correctly copied corrected counts without correction attribution, loss of requested analysis in simplification, and mixed-source claims that drop critical qualifications. One earlier simplification also lacked the required caption in its actual packet. These are distinct failure stages. The old coverage planner asked a model to discover parts, pick quotes and self-report coverage. Its plans omitted the registry role, overran a quote budget, chose a quote under the wrong source, or declared supported parts gaps. Citation-bound output improved a narrow numerical pair yet still allowed a wrong interpretation of conflicting ATOMIC results. The linked-revision and wording experiments did not recover reliable completeness. ## Proposed evaluation-only experiment

1. **Freeze evidence and rubric independently.** Use the existing isolated Ask runner. Hold the Free writer, retrieved sources, exact generation-packet bytes, scope flags and final validators fixed across baseline and candidate. Record hashes and parent lineage. Before exposing outputs, adjudicators write obligations from each question, then label each obligation using the exact packet as supported, conflicting or unavailable. Keep those files outside the runtime prompt. Let supported obligations include their necessary identity, numbers, units, status and scope. An oracle run that injects obligations can diagnose renderer capacity separately.
2. **Build a small evidence index before inference.** Reuse complete matched result, figure-caption, label and correction packets. Give each an opaque ID tied server-side to source ID, packet hash, byte range and known role from verified metadata. Preserve article scope, qualifiers and neighboring group/endpoint context. Only designate a correction as authoritative for the fields it demonstrably amends. Deterministic selectors may use genuinely exposed structure such as an explicit figure label or a stored correction relationship. Preserve ambiguous or conflicting records for adjudication, and avoid assuming a structure exists for arbitrary JATS prose. A fixed wide packet and a fixed sparse packet should both be exercised.
3. **Select and verify bounded claims.** First Free call returns short atomic candidate claims, one or more packet IDs per claim and explicit evidence gaps. For registered structures, emit immutable typed values if independently parsed, including group and analysis population, endpoint, timepoint, signed effect, interval and reported uncertainty type. For ordinary prose, require an exact in-packet supporting span alongside the proposed claim. An application check rejects unknown or mismatched IDs, invalid ranges, unreported numbers, conflicting bindings, unexpected schema fields and over-limit outputs. A second Free call receives the question, original packet index and atomic claims stripped of the first call's rationale. Ask it to return per-claim supported/contradicted/insufficient verdicts with source IDs, and separately identify unanswered requested parts. Compute that audit before rendering. Shared-model agreement is a noisy semantic signal. Independent source adjudication remains the experiment's verifier.
4. **Render accepted records and gaps mechanically.** Produce bounded statements with server-inserted complete citations, using explicit formatting for grouped numeric tuples so confidence bounds, comparison order and populations travel together. Preserve existing answer safety checks over the displayed text and uncertainty. Partial or inconsistent evidence must surface as a scoped gap, never silently disappear. Rejected drafts use the existing fallback and stay visible as failures on supported obligations. For simplification, reuse only accepted claim records from an eligible parent and revalidate their current packet membership. Allow phrasing changes through deterministic formatting and keep all carried qualifiers. Test a rejected or extractive parent separately from a successful parent.

Run offline first with replayed packets and mocked provider responses. Mutate one property at a time: swap arm signs, CI bounds, endpoint or units, substitute the original source for the correction, cite a real span on the wrong analysis, remove a required slot, drop a scope qualifier, and present a valid quote against an unsupported interpretation. Check that structurally detectable mutations fail at the intended stage. Record which cases require semantic review. Include otherwise valid controls to detect over-rejection.

Use the frozen ATOMIC paper and STOIC correction as a targeted paired canary, blinded by candidate label for adjudication. Then use independently authored holdouts for long posted results, protocol-only evidence, a mixed label and registry comparison, a paper with a numerical/narrative conflict, a follow-up chain and the personal-treatment guard. Count each case in its frozen cohort once. Record actual final route, retained parent, support spans, packet presence, reported usage, elapsed time and any provider-blocked cases. Review source scope against the frozen source inventory as well as the exact generation packets. Keep supported-but-omitted, retrieval miss and correct scoped abstention separately observable.

## Proposed acceptance gates

- **Targeted cases.** Every supported critical obligation passes independent review in the displayed answer, including both reported HbA1c uncertainty terms, the signed Figure 2A contrast and interval, endpoint and group semantics, both STOIC analysis populations with the correction directly supporting the amended counts, the open-label qualification when asked, and preservation across simplification. Mortality answers must stay within what the supplied outcomes establish. When a caption is deliberately removed, the case must disclose the missing interval instead of supplying it from unsupported context.
- **Held-out comparison.** Count supported required obligations covered over all supported required obligations, separately from supported atomic claims over all displayed factual claims. Report citation sufficiency and appropriateness separately. Require a gain in supported obligations covered on the targeted set and the held-out set, no lost critical baseline obligation, zero critical unsupported or misattributed claims, and zero new fallbacks on supported canary cases. Count unknown, skipped and provider-limited outcomes explicitly, and only qualify a fully executed mandatory suite. A small suite grades the tested cases only.
- **Runtime and safety.** Keep existing sourcing, numeric and personal-treatment safeguards. The deterministic guard takes zero model calls. Allow up to two calls per eligible candidate and none for offline replay. Keep the existing isolated store, shared evaluation quota and lower application cap. Compare summed actual neurons and per-case wall time with the matched control, and require no increase in either paired median wall time or total neurons across the qualifying suite before promotion. Monitor provider capacity independently of the local reservation balance and stop when quota blocks a request.
